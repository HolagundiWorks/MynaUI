# Conventions

- **Colours only in `O.Ui/Themes/`.** Controls take brushes from theme resources with a fallback equal to the theme value.
- **Brand art is generated** by `tools/Brand`; do not hand-edit generated PNG or ICO files.
- **Accessibility:** WCAG 2.2 AA (text 4.5:1, component edges 3:1); contrast pairs are checked by `tools/a11y/contrast.mjs` in MynaHub.
- **Git.** Add files by name; the default branch is `master`.
