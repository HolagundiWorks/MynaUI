# MynaUI

MynaUI is the shared WinUI 3 library of the Myna suite (assembly `O.Ui`): themes, controls, brand art and the brand generator. MynaHub, MynaOps and MynaCAD reference it by relative path (`..\..\..\MynaUI\O.Ui\O.Ui.csproj`), so the folder must be named `MynaUI` next to the app repositories.
